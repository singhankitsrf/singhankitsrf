# Liver Wala — Production Status

## Public status

**Live web application:** https://liver-wala.singhankitjrf.chatgpt.site

The portfolio treats Liver Wala as a **live production-oriented product implementation**, not as a static mock-up.

## Implemented workflow evidence

- public web access
- separate patient and clinician journeys
- OTP-oriented account-access requirement
- clinician approval state
- 14 hourly appointment windows from 09:00 to 23:00
- payment-confirmation-driven consultation activation
- browser audio/video consultation capability
- clinician-to-patient consultation document delivery
- owner/admin operational visibility

## Claims intentionally not made

The portfolio does not currently claim:

- independently audited uptime/SLA
- independently measured payment-settlement reliability
- penetration-test certification
- medical-device certification
- formal regulatory approval
- hospital-scale concurrency evidence

These are production-assurance milestones for future evidence collection, not assumed properties of the live site.
