# Liver Wala — Live Telemedicine Product Engineering

**Liver Wala** is a live, production-oriented digital-health project built around the complete remote-consultation journey rather than a static healthcare landing page.

**Live application:** https://liver-wala.singhankitjrf.chatgpt.site  
**Hugging Face portfolio surface:** https://huggingface.co/spaces/singhankit491/lw-telemedicine-product

## Product engineering scope

The project connects role-aware user access, clinician onboarding, appointment scheduling, workflow-state progression, browser communication, consultation-document delivery, and operational administration as one coherent product lifecycle.

```text
Patient / Clinician Access
        ↓
Role & eligibility state
        ↓
Appointment availability
        ↓
Confirmed consultation state
        ↓
Browser communication session
        ↓
Consultation document delivery
        ↓
Operational record / follow-up state
```

The current scheduling design supports **14 one-hour appointment windows between 09:00 and 23:00**.

## Why this project matters in the portfolio

Unlike the research- and architecture-heavy AI projects in the wider portfolio, Liver Wala demonstrates **live product ownership**: user journeys, workflow orchestration, state transitions, operational controls, and a publicly accessible service surface.
